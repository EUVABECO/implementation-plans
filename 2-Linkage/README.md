# DATA LINKAGE

# Overview

The purpose of EUVABECO is to deliver to Member States implementation plans for several tools able to support existing or future vaccination practices.

These implementation plans are practical guides for a Member State to decide upon the launch of an implementation project, assign adequate resources, deploy the given tool and keep it operational after deployment.

# Structure

The Linkage implementation plan consists of the following modules.

| Title        | Description      |
|--------------|------------------|
| [Functional description](Linkage%20description.md) | Functional analysis of the Linkage tool with an overview, the stakeholders using or contributing to the use of the tool, their respective functional requirements, the non-functional requirements, and a collection of use cases illustrating the desired functions. |
| [Prerequisites](Linkage%20prerequisites.md)        | Contextual conditions that must be met before the project is launched, and a few workarounds that could be used to anticipate upon their fulfilment.      |
| [Architecture](Linkage%20architecture.md)          | This module details the architecture of the Linkage tool as it as been envisioned and deployed within the EUVABECO project. Assumptions made with this architecture, although minimal, condition the Linkage deployment plan    |
| [Data](Linkage%20data.md)                          | This module details the external data that is needed for the operation of the Linkage tool in terms of content, format and sources. |
| [Security and Privacy](Linkage%20privacy.md)       | This module details the risks for personal data security and privacy incurred within the Linkage tool, and the mitigation measures used to make these risks acceptable.   |
| [Deployment](Linkage%20deployment.md)              | This module describes the resources, workflow and planning for the deployment of the Linkage tool.    |
| [Verification](Linkage%25verification.md)          | This module describes the verifications that should be applied before releasing to production a deployed Linkage. |
| [Operations](Linkage%20operations.md)              | This module proposes an organization and assigns tasks for keeping the Linkage tool operational once it has been deployed.                               |
