MODELLING AND FORECASTING TOOL (FOR)  

# Overview

The purpose of EUVABECO is to deliver to Member States implementation plans for several tools able to support existing or future vaccination practices.

These implementation plans are practical guides for a Member State to decide upon the launch of an implementation project, assign adequate resources, deploy the given tool and keep it operational after deployment.

For each tool, the project will deliver a communication package to the intention of Member States, gathering the implementation plan, evidence about its useability and effectiveness, and proposals for supporting the adoption of the tool and its long-term maintenance.

The communication package consists of modules. Some of them are intended for the implementing team and constitute the implementation plan, while others are addressed to other stakeholders.

# Structure

The forecasting implementation plan consists of the following modules.

| Title                  | Description     |
|------------------------|-----------------|
| [Functional description](02-FOR%20description.md) | Functional analysis of the forecasting tool with an overview, the stakeholders using or contributing to the use of the tool, their respective functional requirements, the non-functional requirements, and a collection of use cases illustrating the desired functions. |
| [Prerequisites](04-FOR%20prerequisites.md)        | Contextual conditions that must be met before the project is launched, and a few workarounds that could be used to anticipate upon their fulfilment.                                                                                                                      |
| [Architecture](08-FOR%20architecture.md)          | This module details the architecture of the forecasting tool as it as been envisioned and deployed within the EUVABECO project. Assumptions made with this architecture, although minimal, condition the forecasting deployment plan described in module 11.              |
| [Data](09-FOR%20data.md)                          | This module details the external data that is needed for the operation of the forecasting tool in terms of content, format and sources.                                                                                                                                   |
| [Security and Privacy](10-FOR%20privacy.md)       | This module details the risks for personal data security and privacy incurred within the forecasting tool, and the mitigation measures used to make these risks acceptable.                                                                                               |
| [Deployment](11-FOR%20deployment.md)              | This module describes the resources, workflow and planning for the deployment of the forecasting tool.                                                                                                                                                                    |
| [Verification](12-FOR%20verification.md)          | This module describes the verifications that should be applied before releasing to production a deployed forecasting tool.                                                                                                                                                |
| [Operations](13-FOR%20operations.md)              | This module proposes an organization and assigns tasks for keeping the forecasting tool operational once it has been deployed.                                                                                                                                            |
