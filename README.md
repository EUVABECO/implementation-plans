# Implementation plans
This repository contains the implementation plans for the 5 EUVABECO tools:
1. [Clinical Decision Support System](1-CDS/README.md)
1. [Linkage](2-Linkage/README.md)
1. [Electronic Patient Information Leaflet](3-ePIL/README.md)
1. [Modelling and forecasting](4-Forecasting/README.md)
1. [European vaccination card](5-EVC/README.md)

Each implementation plan is complemented with supporting resources for implementers.

> These plans are exposed at https://plans.euvabeco.eu and editable from the [EUVABECO GitHub repository]( https://github.com/EUVABECO/implementation-plans/)
